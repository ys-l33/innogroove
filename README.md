# INNOGROOVE

**Find your groove, Make a move.**

광고 회사 직원들의 업무 생산성을 높여주는 플레이리스트 생성기. 블랙 & 라임(`#000000` / `#a8f11b`)을 메인으로, 핑크(`#f137b3`)를 서브 포인트로 쓰는 다크 테마 대시보드입니다.

## 사용 흐름

플레이리스트를 만드는 두 가지 방법을 제공합니다.

1. **커스텀 프롬프트로 만들기** — 지금 어떤 피드백을 받고 무슨 작업 중인지 문장으로 입력하면, 그에 맞춰 정렬된 트랙 리스트가 생성됩니다.
2. **컨셉 큐레이션 — 광고인의 하루** — 직접 안 써도 되는 4가지 상황별 테마 카드 중 하나를 고르면 바로 생성됩니다.
   - 📁 `'수정 지옥' 믹스` — 지금 열려있는 파일 이름(`제안서_초안.pptx` 등)으로 오늘의 멘탈 상태를 고르면 그에 맞는 곡
   - ⚡ `경쟁 PT 전야제 '도파민 부스터'` — 프레젠테이션 전야, 사기를 끌어올리는 트랙
   - 🔍 `트렌드 레퍼런스 디깅` — 숏폼·광고제 감성 영감 수집용 트렌디한 트랙
   - 🎉 `'컨펌 완료' 멘탈 케어` — 컨펌 직후 스스로를 다독이는 따뜻한 트랙

이후 흐름은 동일합니다.

3. 마음에 드는 곡은 좋아요, 빼고 싶은 곡은 X 표시 → "이대로 플레이리스트를 완성할까요?"에 아니요를 선택하면 선호도를 반영해 재추천 (반복 가능). X로 제외한 카드는 프로스티드 글래스 오버레이로 표시되며, 오버레이에 마우스를 올리면 "취소하기"로 바뀌어 클릭 한 번에 복구할 수 있습니다.
4. 만족하면 버전 우선순위(오리지널/리마스터/라이브)와 이동할 플랫폼(유튜브 뮤직/스포티파이/애플 뮤직)을 선택해 각 곡의 검색 결과 페이지로 이동합니다.

## UI/UX 하이라이트

- **전역 배경**: 애니메이션 메시 그라데이션 + 노이즈 텍스처가 모든 화면 전환에 걸쳐 끊김 없이 유지됩니다.
- **GlobalHeader**: INNOGROOVE 뱃지와 메인 타이틀을 전 화면 공통 헤더로 분리, 클릭하면 어디서든 메인 화면으로 돌아갑니다. 서브 화면에서는 크기와 여백을 대폭 줄여 GNB처럼 표시됩니다.
- **FlowText**: `groove`/`move` 같은 강조 단어에 마우스를 올리면 라임 → 핑크 그라데이션이 커서를 따라 흐르는 인터랙션.
- **가사 룰렛(Ad-Lyrics Roulette)**: 광고를 시적이고 긍정적으로 노래하는 가사 카드 이스터에그. 클릭하면 랜덤으로 가사가 바뀌며, `ad`/`ads`/`advertising`/`advertisement`/`광고` 키워드에 라임-핑크 그라데이션 하이라이팅이 적용되고, 미니 이퀄라이저(4바)가 항상 은은하게 움직입니다.
- **트랙 카드**: 좋아요한 곡은 네온 핑크 글로우, 제외한 곡은 프로스티드 글래스 오버레이로 표시.
- **좌측 하단 디지털 시계 / 우측 하단 홈 복귀 버튼("i wanna go back home")**: 서브 화면에서만 나타나며, 하단에 고정 CTA 바가 있는 화면(플레이리스트 생성 화면)에서는 자동으로 위치가 올라가 바에 가려지지 않습니다.
- 화면(스테이지)이 전환될 때마다 스크롤이 항상 맨 위로 초기화됩니다.
- 마퀴 배너, 네온 글로우 버튼, 카드 호버 글로우, 개념별 클릭 파티클 이펙트 등 모션 디테일.

> 이 프로젝트는 URL 라우팅(react-router-dom) 대신 `src/App.tsx`의 단일 `Stage` 상태 머신(`search` → `playlist` → `options` → `redirect`)으로 화면을 전환합니다.

## 기술 스택

- React 19 + TypeScript + Vite 7
- Tailwind CSS v4 (`@tailwindcss/vite`)
- `vite-react-ssg` (single-page 모드)로 정적 렌더링 — 빌드 결과물에 실제 텍스트가 포함되어 크롤러가 읽을 수 있습니다.
- 로컬 `Pretendard`(한글) + Google Fonts `Outfit`(영문) 폰트 조합
- GitHub Actions로 GitHub Pages(`/innogroove/` 서브패스)에 자동 배포

## 참고 (프로토타입 한계)

- 추천 로직은 목업 트랙 데이터베이스(`src/data/tracks.ts`)와 키워드 기반 매칭(`src/lib/matcher.ts`)으로 동작하는 프로토타입이며, 실제 AI 추천이나 음원 스트리밍 API를 사용하지 않습니다.
- 플랫폼 자동 플레이리스트 생성은 각 서비스의 OAuth 인증이 필요해 지원하지 않으며, 대신 곡별 검색 결과 페이지로 연결합니다.
