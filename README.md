# Focus Flow

작업 생산성을 높여주는 프롬프트 기반 플레이리스트 생성기 프로토타입.

## 사용 흐름

1. 원하는 분위기를 문장으로 입력 (예: "펑키함을 살린 밴드 노래 플레이리스트")
2. 프롬프트에 맞춰 정렬된 플레이리스트가 생성됨
3. 마음에 드는 곡은 좋아요, 빼고 싶은 곡은 삭제 표시 → "이 플레이리스트로 재생할까요?" 질문에 아니요를 선택하면 선호도를 반영해 재추천 (반복 가능)
4. 만족하면 리마스터/라이브 버전 우선 여부와 이동할 플랫폼(유튜브 뮤직/스포티파이/애플 뮤직)을 선택해 각 곡의 검색 결과 페이지로 이동

## 참고

- 추천 로직은 목업 트랙 데이터베이스(`src/data/tracks.ts`)와 키워드 기반 매칭(`src/lib/matcher.ts`)으로 동작하는 프로토타입입니다.
- 플랫폼 자동 플레이리스트 생성은 각 서비스의 OAuth 인증이 필요해 이번 단계에서는 지원하지 않으며, 대신 곡별 검색 결과로 연결합니다.

## 개발

```bash
npm install
npm run dev
```
